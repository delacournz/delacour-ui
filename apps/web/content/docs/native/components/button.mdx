## Sizes

One axis drives five values: the height, the label's type scale, the icon step, the horizontal
padding and the corner. `--radius-button-*` is half each height, so a button is a capsule by
default and a square one a circle. Square one off with `className="rounded-lg"`, or retune the
three tokens to change every button at once.

<Preview id="button/sizes" />

```tsx
<Button size="sm">Small</Button>
<Button size="md">Medium</Button>
<Button size="lg">Large</Button>
```

The same axis carries the square sizes — see [Icon button](#icon-button).

## Icons

Icons are composed, not passed as props — put an `Icon` in the children, before or after the label.

<Preview id="button/icons" />

```tsx
import { Icon } from "@delacour/native-ui/icon";
import { IconArrowRight, IconTrash } from "@delacour/native-ui/icons/central";

<Button onPress={next}>
  <Button.Label>Continue</Button.Label>
  <Icon icon={IconArrowRight} />
</Button>

<Button variant="destructive" onPress={remove}>
  <Icon icon={IconTrash} />
  <Button.Label>Delete</Button.Label>
</Button>
```

The button publishes its size and its variant's foreground token to the subtree, so a bare `<Icon>`
comes out right with nothing said at the call site. An explicit `size` or `color` still wins.

## Icon button

Use an `icon-*` size for a square button whose only content is an icon. Each one is its labelled
step — the same height, corner and icon token — with the horizontal padding traded for a width off
that step's own token, so the footprint is square by construction rather than by two numbers
agreeing.

<Preview id="button/icon-button" />

```tsx
<Button accessibilityLabel="Favourite" size="icon-md" variant="ghost">
  <Icon icon={IconHeart} />
</Button>
```

`icon-sm`, `icon-md` and `icon-lg` are 36, 44 and 52 points square — the same three heights the
labelled sizes stand at, so an icon button sits level with the text button beside it.

<Callout type="warn">
Always pair an `icon-*` size with an `accessibilityLabel`. There is no text for a screen reader to
fall back on.
</Callout>

## Loading

Use `isLoading` to compose a spinner in and block presses.

```tsx
<Button isLoading onPress={save}>Save</Button>
```

The spinner takes the place of the composed `Icon` rather than joining it, so nothing shifts when
work begins.

## Spinner placement

Use `spinnerPlacement` to choose which side the spinner takes, or `only` to replace the content.

```tsx
<Button isLoading spinnerPlacement="start">Save</Button>
<Button isLoading spinnerPlacement="end">Save</Button>
<Button isLoading spinnerPlacement="only">Save</Button>
```

<Callout title="Loading is not disabled">
`isLoading` blocks the press and announces the button as *busy*, but keeps full contrast. Pass
`isDimmedWhileLoading` to opt into the faded treatment.
</Callout>

## Press feedback

A button is a `Pressable`, so `feedback`, `haptic` and `pressedScale` are inherited. Only the
default differs — `scale`.

```tsx
<Button feedback="fade">Fade on press</Button>
<Button haptic="selection">With haptic</Button>
<Button pressedScale={0.92}>Deeper press</Button>
```

## Reading the button's state

Use `useButton()` to match the parent from a custom child, without prop drilling.

```tsx
import { useButton } from "@delacour/native-ui/button";

function ButtonCount({ count }: { count: number }) {
  const { variant, size, isDisabled } = useButton();
  // …
}
```

### Exports

```tsx
import {
  BUTTON_VARIANTS,
  BUTTON_SIZES,
  BUTTON_LABEL_SIZES,
  BUTTON_ICON_SIZES,
  BUTTON_SPINNER_PLACEMENTS,
  BUTTON_FOREGROUND_TOKEN,
  buttonVariants,
} from "@delacour/native-ui/button";
```

`BUTTON_SIZES` is every value `size` accepts. `BUTTON_LABEL_SIZES` and `BUTTON_ICON_SIZES` are the
two families it is composed from — map one when a list should hold only labelled buttons, or only
square ones.

`BUTTON_FOREGROUND_TOKEN` maps each variant to the theme token its icons and text are drawn in.
`buttonVariants` is the `tv()` slot set — useful when building a component that has to match a
button exactly.
