## Tap or drag

A tap toggles; a drag carries the thumb and settles on release by position, or by the flick's
velocity if you let go fast.

## Start and end content

Both layers are written once with no conditionals — `StartContent` is revealed as the switch turns
on and `EndContent` as it turns off, each fading with the thumb's travel.

<Preview id="switch/start-and-end-content" />

```tsx
import { Icon } from "@delacour/native-ui/icon";
import { IconCheckmark1Small, IconX } from "@delacour/native-ui/icons/central";

<Switch color="primary" defaultSelected>
  <Switch.StartContent>
    <Icon icon={IconCheckmark1Small} />
  </Switch.StartContent>
  <Switch.EndContent>
    <Icon icon={IconX} />
  </Switch.EndContent>
</Switch>
```

The glyphs take their size step and colour from the switch.

## In a settings list

The row's own press toggles the switch, in a `ListGroup.Item` or in an enclosing
[`Field`](/docs/native/components/field) — so a form switch can be a bare `<Switch />` with
`Field.Label` naming it.

```tsx
<ListGroup.Item onPress={toggle}>
  <ListGroup.ItemPrefix>
    <Icon icon={IconBell} />
  </ListGroup.ItemPrefix>
  <ListGroup.ItemContent>
    <ListGroup.ItemTitle>Notifications</ListGroup.ItemTitle>
  </ListGroup.ItemContent>
  <ListGroup.ItemSuffix>
    <Switch accessibilityLabel="Notifications" color="success" isSelected={on} onSelectedChange={setOn} size="sm" />
  </ListGroup.ItemSuffix>
</ListGroup.Item>
```

## API Reference

### Anatomy

| Part | What it is |
| --- | --- |
| `Switch` | The track. Owns the gesture, the spring and the state |
| `Switch.Thumb` | The knob. Composed in automatically; write it out to restyle it or fill it |
| `Switch.StartContent` | Behind the thumb at the leading edge — revealed as the switch turns on |
| `Switch.EndContent` | Behind the thumb at the trailing edge — revealed as the switch turns off |
