<ComponentInstall name="scroll-text" />

## Usage

```tsx title="app/index.tsx"
import { Screen } from "@/components/ui/screen";
import { ScrollText } from "@/components/ui/scroll-text";

export default function Example() {
  return (
    <Screen>
      <Screen.ScrollArea>
        <ScrollText size="2xl" weight="semibold">
          We build interfaces that move when you do.
        </ScrollText>
      </Screen.ScrollArea>
    </Screen>
  );
}
```

## Wiring the scroll position

`source` reads the enclosing `Screen` by default; pass any scroll view's offset, and its ref as
`viewport` when it is smaller than the screen.

```tsx
const scrollY = useSharedValue(0);
const viewport = useAnimatedRef<Animated.ScrollView>();
const onScroll = useAnimatedScrollHandler((event) => {
  scrollY.value = event.contentOffset.y;
});

<Animated.ScrollView onScroll={onScroll} ref={viewport} scrollEventThrottle={16}>
  <ScrollText source={{ kind: "offset", scrollY, viewport }}>Every word waits its turn.</ScrollText>
</Animated.ScrollView>
```

<Callout>
With the default `screen` source and no `Screen` above it, the text renders fully revealed and does
not move — a development build warns once.
</Callout>

## Effects

`colour` (the default) goes from `muted-foreground` to `foreground`, `fade` and `rise` lift opacity
from a 0.15 floor, and `highlight` fills a band behind each unit.

```tsx
<ScrollText effect={{ kind: "colour", from: "muted-foreground", to: "primary" }}>…</ScrollText>
<ScrollText effect={{ kind: "fade", from: 0.2 }}>…</ScrollText>
<ScrollText effect={{ kind: "rise", distance: 16 }}>…</ScrollText>
<ScrollText effect={{ kind: "highlight" }}>…</ScrollText>
```

## Splitting and stagger

`split` picks the unit — `word`, `character` or `line` — and `overlap` runs from 0, one after
another, to 1, all together.

```tsx
<ScrollText split="character" overlap={0.1} effect={{ kind: "fade" }}>Letter by letter.</ScrollText>
<ScrollText split="line" effect={{ kind: "rise", distance: 10 }}>…</ScrollText>
```

## Setting the window

`window` gives the viewport fractions, 0 at the top, where the block's top edge starts and finishes
its reveal.

```tsx
<ScrollText window={{ start: 1, end: 0.5 }}>Finishes by the middle of the screen.</ScrollText>
```

## Driving it from something else

A `progress` source takes a shared value already in 0..1, so a slider, a pager or a gesture can drive it.

```tsx
const progress = useSharedValue(0);

<ScrollText source={{ kind: "progress", progress }}>The same text, by hand.</ScrollText>
```

## Reduced motion

Under reduce motion and `DelacourProvider`'s [`isMotionCalm`](/docs/native/getting-started/provider)
the text is fully revealed and nothing moves.

## Accessibility

The block is one element that reads the whole string once; the units are hidden from assistive
technology.
