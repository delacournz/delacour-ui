## Usage

```tsx title="app/index.tsx"
import { Avatar } from "@/components/ui/avatar";
import { View } from "react-native";

export default function Example() {
  return (
    <View className="flex-1 items-center justify-center p-4">
      <Avatar name="Kate Austen" source={{ uri: "https://i.pravatar.cc/160?img=47" }} />
    </View>
  );
}
```

## Image and fallbacks

The initials show while the image loads, and in its place if it fails, so a dead URL never leaves an empty circle.

<Preview id="avatar/fallbacks" />

```tsx
<Avatar name="Kate Austen" source={{ uri: user.avatarUrl }} />
<Avatar name="Oliver Lee" />
<Avatar fallback="DX" name="Design Crew" />
<Avatar />
```

## Sizes

A size is a fixed edge — 32, 40, 48 and 64 points.

<Preview id="avatar/sizes" />

```tsx
<Avatar name="Ana Silva" size="sm" />
<Avatar name="Ben Okafor" size="md" />
<Avatar name="Chen Wei" size="lg" />
<Avatar name="Dana Kim" size="xl" />
```

## Variants and colours

`variant` and `color` paint the fallback, on the six colours `Badge` takes.

<Preview id="avatar/variants-and-colours" />

```tsx
<Avatar name="Pri Mary" variant="soft" color="primary" />
<Avatar name="Sue Cess" variant="solid" color="success" />
```

## Presence

An empty `Avatar.Badge` is a presence dot; say the status in the avatar's own label.

<Preview id="avatar/presence" />

```tsx
<Avatar accessibilityLabel="Kate Austen, online" name="Kate Austen" source={photo}>
  <Avatar.Badge color="success" placement="bottom-right" />
</Avatar>
```

## Unread count

Given children, `Avatar.Badge` only pins them to the corner.

<Preview id="avatar/unread-count" />

```tsx
import { Badge } from "@/components/ui/badge";

<Avatar name="Oliver Lee" source={photo}>
  <Avatar.Badge>
    <Badge color="destructive" size="sm">3</Badge>
  </Avatar.Badge>
</Avatar>;
```

## Pressable avatars

With no `onPress` and no `onLongPress` the root is a plain `View`; supply either and it becomes a `Pressable`.

```tsx
<Avatar name="Oliver Lee" onPress={openProfile} />
```

## Group

`max` caps the faces, not the row, and `total` counts people who were never passed as children.

```tsx
<Avatar.Group max={3} total={40}>
  <Avatar name="Kate Austen" source={kate} />
  <Avatar name="Oliver Lee" source={oliver} />
  <Avatar name="Chen Wei" />
</Avatar.Group>
```

## Overlap

`overlap` defaults to a third of the edge; `0` closes the stack into a plain row.

```tsx
<Avatar.Group overlap={0} size="sm">…</Avatar.Group>
```

## API Reference

### AvatarProps

A pressable avatar is a `Pressable`, so `feedback`, `haptic`, `onPress` and the rest are inherited rather than
restated — see [Pressable](/docs/native/components/pressable). `asChild`, `busy` and `disabled` are withheld: use
`isDisabled`.
