## How it reads the theme

The selection is Uniwind's, not the component's: System is selected while the app follows the
device, so a theme changed anywhere else re-selects every mounted selector.

```tsx
<ThemeSelector onValueChange={(mode) => console.log(mode)} />
```

## Modes and labels

`modes` picks the options and their order, and `labels` renames them for localisation.

```tsx
<ThemeSelector labels={{ light: "Day", dark: "Night" }} modes={["light", "dark"]} />
```

## Persisting the choice

Uniwind forgets its theme on restart; with `applyTheme={false}` the selector only reports, so the
app saves the choice, applies it and passes the saved mode back as `value`.

<Preview id="theme-selector/persisted" />

```tsx
import { restoreThemeMode, ThemeSelector, type ThemeMode } from "@/components/ui/theme-selector";
import { useState } from "react";
import { createMMKV } from "react-native-mmkv";
import { Uniwind } from "uniwind";

const storage = createMMKV();

Uniwind.setTheme(restoreThemeMode(storage.getString("theme")));

export function AppearanceSetting() {
  const [saved, setSaved] = useState<ThemeMode>(() => restoreThemeMode(storage.getString("theme")));

  return (
    <ThemeSelector
      applyTheme={false}
      onValueChange={(mode) => {
        storage.set("theme", mode);
        setSaved(mode);
        Uniwind.setTheme(mode);
      }}
      value={saved}
    />
  );
}
```

<Callout type="warn">
  `Uniwind.setTheme` throws on a name it does not know. Pass a stored string through
  `restoreThemeMode`, which falls back to `"system"`, rather than straight to `setTheme`.
</Callout>

## In a field

Inside a `Field`, the label names the group and `isDisabled` cascades.

<Preview id="theme-selector/in-field" />

```tsx
<Field>
  <Field.Label>Appearance</Field.Label>
  <ThemeSelector variant="cards" />

```

## useThemeSelection

The live mode, what it resolves to and a setter, with no selector mounted — for a custom control or
a row that only shows the choice.

```tsx
const { mode, resolved, setMode } = useThemeSelection();
```

## Accessibility

The group is a `radiogroup` named by `accessibilityLabel`, the enclosing `Field.Label`, or "Theme";
each option is a `radio` announced by its label.
