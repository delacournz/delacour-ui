<Preview id="text/type-scale" />

<Preview id="text/inline-presets" />

<Callout type="warn" title="A nested Text.Code cannot be padded">
A nested `<Text>` is laid out by the platform's text engine — an `NSAttributedString` run on iOS, a
`Span` on Android — and both ignore padding, margin and border radius on an inner `<Text>`. Only the
background survives. The pill treatment applies to the standalone case only; a code *block* is a
`View` you wrap around it.
</Callout>

## Inheritance

Every `Text` publishes its resolved class to its subtree, and merges the one it inherited.

<Preview id="text/nesting" />

```tsx
<Text.Paragraph>
  Sign in with <Text.Strong>your work account</Text.Strong> to continue.
</Text.Paragraph>
```

`Text.Strong` comes out at the paragraph's size and colour with only the weight changed. A `Button`
publishes its label's treatment the same way, so a bare `<Text>` composed into one needs nothing at
the call site.

## Axes

```tsx
<Text size="lg" weight="semibold" color="muted" align="center" transform="uppercase">
  Heads up
</Text>
```

Each axis beats the variant's own value and anything inherited; omit an axis and it falls through to
the enclosing text.

<Callout type="warn" title="An arbitrary font size must be a length">
Write `text-[17px]` or `text-(length:--x)`. A bare `text-[var(--x)]` is ambiguous to tailwind-merge,
which files it under colour — so it will not override the inherited size.
</Callout>

## Colour

`color` is page-level only. Text on a coloured surface writes the utility in a `className`, because
that mapping belongs to the surface.

<Preview id="text/colour" />

```tsx
<Text color="danger">Could not save</Text>
```

## Truncation

<Preview id="text/truncation" />

```tsx
<Text.Paragraph numberOfLines={2}>{body}</Text.Paragraph>
```

## Font scaling

`allowFontScaling` is left at React Native's default, and `maxFontSizeMultiplier` defaults to
`TEXT_MAX_FONT_SIZE_MULTIPLIER` so a label cannot outgrow the fixed-height chrome around it.

```tsx
<Text allowFontScaling={false}>Fixed</Text>
<Text maxFontSizeMultiplier={2}>Room to grow</Text>
```
