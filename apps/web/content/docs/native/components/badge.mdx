## Usage

```tsx title="app/index.tsx"
import { Badge } from "@/components/ui/badge";
import { View } from "react-native";

export default function Example() {
  return (
    <View className="flex-1 items-center justify-center p-4">
      <Badge color="success">Active</Badge>
    </View>
  );
}
```

## Variants and colours

`variant` says how the surface is painted; `color` says what it means.

<Preview id="badge/variants-and-colours" />

```tsx
<Badge variant="solid">Default</Badge>
<Badge variant="soft" color="success">Active</Badge>
<Badge variant="outline" color="warning">Pending</Badge>
<Badge variant="ghost" color="destructive">Failed</Badge>
```

## Sizes

A size sets padding and the label's type scale, never a height, so the badge grows with OS font
scaling instead of clipping.

<Preview id="badge/sizes" />

```tsx
<Badge size="sm">Small</Badge>
<Badge size="md">Medium</Badge>
<Badge size="lg">Large</Badge>
```

## Icons

Icons are composed, not passed as props — put an `Icon` in the children, before or after the label.

<Preview id="badge/composed-icon" />

```tsx
import { Icon } from "@delacour/react-native-ui/icon";
import { IconStar } from "@delacour/react-native-ui/icons/central";

<Badge variant="soft" color="warning">
  <Icon icon={IconStar} />
  <Badge.Label>Premium</Badge.Label>
</Badge>;
```

The badge publishes its icon size and its variant's foreground token to the subtree, so a bare
`<Icon>` or `<Text>` comes out right with nothing said at the call site.

## Trailing icons

```tsx
<Badge color="success">
  <Badge.Label>Verified</Badge.Label>
  <Icon icon={IconCheckmark1Small} />
</Badge>
```

## Start and end content

Use `Badge.StartContent` or `Badge.EndContent` for leading and trailing content that is not an
`Icon`.

<Preview id="badge/status-dot" />

```tsx
<Badge variant="soft" color="success">
  <Badge.StartContent>
    <View className="size-1.5 rounded-full bg-success" />
  </Badge.StartContent>
  <Badge.Label>Online</Badge.Label>
</Badge>
```

## Counts

Pass `count` instead of children. One digit sits in a circle and more in a capsule; past `max` the
number stops at `99+`. A count of zero draws nothing, so there is no condition to write — set
`showZero` to keep it.

<Preview id="badge/counts" />

```tsx
<Badge color="destructive" count={3} />
<Badge color="destructive" count={128} />
<Badge color="destructive" count={12} max={9} />
<Badge count={0} showZero />
```

## Dots

A badge with no children and no count is a dot. It is solid in its `color` whatever the `variant`.

<Preview id="badge/dots" />

```tsx
<Badge color="success" />
<Badge color="destructive" size="lg" />
```

## Pinned to a corner

`placement` pins a badge to a corner of its parent. Wrap the pair in a `Badge.Anchor`, which sizes
the parent to what it holds — without it, a `View` in a column stretches and the corner is the far
edge of the screen.

<Preview id="badge/pinned" />

```tsx
<Badge.Anchor accessible accessibilityLabel={`Inbox, ${unread} unread`}>
  <Icon icon={IconEmail1} size="lg" />
  <Badge color="destructive" count={unread} placement="top-right" size="sm" />
</Badge.Anchor>
```

The badge is pinned by its inner edge, so a count that gains a digit grows away from the glyph
rather than across it. A dot or a count says nothing useful to a screen reader on its own — put the
meaning into the `accessibilityLabel` of the thing it sits on.

An [`Avatar`](/docs/native/components/avatar) pins its own: put the badge in an `Avatar.Badge` and
leave `placement` off.

## Pressing and dismissing

A badge is read-only: it takes no `onPress` and no `onClose`. Something a user taps, toggles or
removes is a [`Chip`](/docs/native/components/chip), which shares Badge's colours and tones.

```tsx
<Chip onClose={remove}>Design</Chip>
```

## API Reference

### BadgeProps

A badge is a `View`, so `style`, `testID` and the accessibility props are inherited rather than
restated. `count` and `children` are alternatives: passing both is a type error.

### Badge.Label

The badge's text. Picks its colour and type scale from the badge's variant, colour and size.
Extends React Native's `TextProps`.

### Badge.StartContent / Badge.EndContent

Centred wrappers for leading and trailing content that is not an `Icon`. An `Icon` needs neither —
it inherits the badge's icon size and its colour from the subtree.
