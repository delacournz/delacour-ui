Nineteen components, each on its own import subpath. There is no package-wide barrel — that is
what lets an app skip resolving optional peers it never uses.

Every page carries the same three ways in, and the name is the same in all of them:

<InstallTabs commands={[{ verb: "dlx", packages: ["delacour@latest add button"] }]} />

<InstallTabs commands={[{ verb: "add", packages: ["@delacour/native-ui"] }]} />

The CLI copies the source into your repository, so you edit `button.tsx` rather than upgrade a
package. The package installs the same components and you import them from
`@delacour/native-ui/button`. The **Manual** tab on each page lists the exact files, if you would
rather copy them yourself. See [Installation](/docs/native/getting-started/installation).
