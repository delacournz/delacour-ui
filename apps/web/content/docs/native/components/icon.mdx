## Sizes

`xs` 14, `sm` 16, `md` 18, `lg` 20, `xl` 24, `2xl` 32 — the shared icon scale, which `Spinner`
reads too.

<Preview id="icon/the-size-scale" />

```tsx
<Icon icon={IconHeart} size="sm" />
<Icon icon={IconHeart} size={22} />
```

A named step is a class; a number bypasses the class chain entirely. The precedence ladder is in
[Sizing](/docs/native/getting-started/sizing#precedence-weakest-first), and the full guide to the
set is [Icons](/docs/native/getting-started/icons).

## Inherited defaults

A bare `<Icon>` takes its size and colour from the nearest provider.

<Preview id="icon/inherited-from-a-button" />

```tsx
import { IconDefaultsProvider } from "@delacour/native-ui/icon";

<IconDefaultsProvider value={{ className: "size-icon-lg", color: "muted-foreground" }}>
  {children}
</IconDefaultsProvider>;
```

## A subtree of defaults

```tsx
<IconDefaultsProvider value={{ className: "size-icon-2xl", color: "primary" }}>
  <Icon icon={IconHeart} />
  <Icon color="destructive" icon={IconBell} />
</IconDefaultsProvider>
```

`Button`, `Badge` and `ListGroup.ItemPrefix` all publish into this, so a bare `<Icon>` inside one
needs nothing at the call site. An explicit `size` or `color` still wins.
