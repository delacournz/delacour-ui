## Usage

```

```

## Dividers

The root puts a `Separator` between adjacent children, inset to line up with the rows' padding.

<Preview id="list-group/dividers" />

```tsx
<ListGroup isDivided={false}>…</ListGroup>
```

A `Separator` placed by hand suppresses the automatic one on either side of it, so one gap can be
full-bleed without turning the feature off.

## Row slots

<Preview id="list-group/custom-suffix" />

```tsx
import { Icon } from "@delacour/native-ui/icon";
import { IconUser } from "@delacour/native-ui/icons/central";

<ListGroup.Item onPress={openProfile}>
  <ListGroup.ItemPrefix>
    <Icon icon={IconUser} />
  </ListGroup.ItemPrefix>
  <ListGroup.ItemContent>
    <ListGroup.ItemTitle>Profile</ListGroup.ItemTitle>
    <ListGroup.ItemDescription>Name, photo and handle</ListGroup.ItemDescription>
  </ListGroup.ItemContent>
  <ListGroup.ItemSuffix />
</ListGroup.Item>;
```

`ItemPrefix` wraps its subtree in icon defaults, so a bare `<Icon>` needs nothing said at the call
site. `ItemSuffix` draws a chevron when it has no children of its own.

### ListGroup.ItemTitle / ItemDescription

The row's two lines of text. Extend React Native's `TextProps`.

<TypeTable type={{ className: { type: "string" }, children: { type: "ReactNode" } }} />

<Callout type="warn">
Title colour goes on the title, never on the row. A row is a `View`, and a React Native `View` does
not cascade colour to a `Text` descendant — the `item` slot carries no `text-*` at all, so a
`text-danger` written there does nothing.
</Callout>
