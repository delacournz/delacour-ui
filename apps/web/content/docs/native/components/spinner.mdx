```

```

## Sizes

The icon scale, shared outright — `SPINNER_SIZES` *is* `ICON_SIZES`, `xs` through `2xl`
(14/16/18/20/24/32pt) — or an explicit number.

<Preview id="spinner/sizes" />

```tsx
<Spinner size="sm" />
<Spinner size="lg" />
<Spinner size={40} />
```

## Colours

`default`, `success`, `warning` and `destructive`, plus any token the theme emits
(`primary-foreground`, `muted-foreground`) or a literal (`#EC4899`).

<Preview id="spinner/colours" />

```tsx
<Spinner color="destructive" />
<Spinner color="muted-foreground" />
<Spinner color="#EC4899" />
```

<Callout>
A Tailwind palette name like `emerald-500` only resolves if some utility class already pulled that
variable into the build — otherwise the token is unresolved and nothing is drawn. Prefer the
semantic tokens.
</Callout>

## Inherited size and colour

Both come from the nearest `IconDefaultsProvider`, falling back to `md` on `foreground`. An explicit
`size` or `color` always wins.

## Custom glyphs

Any child is the glyph, wrapped in a `Spinner.Content` automatically so it still rotates.

```tsx
<Spinner color="destructive" size="lg" speed={0.4}>
  <Icon icon={IconArrowsRepeatCircle} />
</Spinner>
```

`speed` belongs to the root and rides the spinner's context, so every part turns at one rate: `1` is
one full turn per 900ms.
