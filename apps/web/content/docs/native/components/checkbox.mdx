## Usage

```tsx
import { Checkbox } from "@delacour/native-ui/checkbox";
```

```tsx
<Checkbox isChecked={accepted} onCheckedChange={setAccepted}>
  <Checkbox.Label>Accept the terms</Checkbox.Label>
</Checkbox>
```

## Indeterminate

`isIndeterminate` paints the surface, swaps the glyph and reports `checked="mixed"` — so a "select
all" row says what it means rather than claiming a half-truth.

<Preview id="checkbox/indeterminate" />

```tsx
<Checkbox isIndeterminate isChecked={all} onCheckedChange={toggleAll}>
  <Checkbox.Label>Select all</Checkbox.Label>
</Checkbox>
```

## Groups

`Checkbox.Group`'s state is one array of the children's `value`s.

<Preview id="checkbox/checkbox-group" />

```tsx
<Checkbox.Group checked={selected} onChecked={setSelected}>
  <Checkbox value="email"><Checkbox.Label>Email</Checkbox.Label></Checkbox>
  <Checkbox value="push"><Checkbox.Label>Push</Checkbox.Label></Checkbox>
</Checkbox.Group>
```

The group carries shared defaults for the paint and state axes, which resolve
`own ?? group ?? field ?? default`.

<Callout type="warn">
Inside a group, a checkbox's `value` is required — the group tracks selection by it. A box without
one is invisible to the group's `checked` array, so it renders but never reports.
</Callout>

## Inside a field

The box hands its toggle back up, so a form checkbox can be a bare `<Checkbox />` with
`Field.Label` naming it and the whole row driving it.

```tsx
<Field orientation="horizontal">
  <Field.Label>Accept the terms</Field.Label>
  <Checkbox isChecked={accepted} onCheckedChange={setAccepted} />
</Field>
```

Use `Field.Label` in a horizontal `Field`, and `Checkbox.Label` everywhere else.

## API Reference

### Checkbox

A checkbox is a `Pressable`, so `feedback`, `haptic` and the rest are inherited — see
[Pressable](/docs/native/components/pressable). `onPress` is withheld in favour of
`onCheckedChange`, and `disabled` in favour of `isDisabled`, which the label reads through context.

### Checkbox.Group

Owns the selection for the boxes inside it, and publishes the shared axes so each one does not
restate them. Extends `ViewProps`.
