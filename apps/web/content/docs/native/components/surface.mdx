## Usage

```tsx title="app/index.tsx"
import { Surface } from "@/components/ui/surface";
import { Text } from "@/components/ui/text";
import { View } from "react-native";

export default function Example() {
  return (
    <View className="flex-1 justify-center p-4">
      <Surface className="gap-3">
        <Text.Label>Account</Text.Label>
        <Surface>
          <Text.Caption>Signed in as sam@example.com</Text.Caption>
        </Surface>
      </Surface>
    </View>
  );
}
```

## Variants

`default` is the card, hairlined so it holds its edge on the page; `transparent` paints nothing.

<Preview id="surface/variants" />

```tsx
<Surface variant="secondary">…</Surface>
<Surface variant="tertiary">…</Surface>
<Surface variant="transparent">…</Surface>
```

## Padding

<Preview id="surface/padding" />

```tsx
<Surface padding="none">…</Surface>
<Surface padding="sm">…</Surface>
<Surface padding="lg">…</Surface>
```

## Nesting

A surface that names no variant steps to the next fill from the one it sits in, so it never vanishes into its parent.

<Preview id="surface/nesting" />

```tsx
<Surface>
  <Surface>
    <Surface>…</Surface>
  </Surface>
</Surface>
```

## Transparent

A transparent surface passes the plane beneath it through, so a surface inside it still steps from the card.

<Preview id="surface/transparent" />

```tsx
<Surface>
  <Surface variant="transparent">
    <Surface>…</Surface>
  </Surface>
</Surface>
```

## Bleed

`padding="none"` clips, so content bled to the edge takes the surface's corner with it.

<Preview id="surface/bleed" />

```tsx
<Surface padding="none">
  <Image className="h-28 w-full" source={cover} />
  <View className="p-4">…</View>
</Surface>
```

### useSurface

Reads the enclosing surface's fill, for a custom child that has to match it. Throws outside a `Surface`.

<Callout type="warn">
A surface does not colour its text. A React Native `View` does not cascade colour to a `Text`
descendant, so a `text-*` class on a `Surface` does nothing — put it on the `Text`.
</Callout>
