Nineteen components, each on its own import subpath. There is no package-wide barrel — that is
what lets an app skip resolving optional peers it never uses.

<Callout title="Or own the source instead">
Every component here can be copied into your own repository with the
[`delacour` CLI](/docs/native/cli) — `bunx delacour@latest add button`. The name after `add` is the
same one as the import subpath. Same components, different delivery: you edit the file rather than
upgrade a package.
</Callout>
