By the end of this page an Expo app is running on a simulator with a Button that counts its
presses, styled from the same tokens as your web app. Nothing here is explained yet — every
command is copyable, and each links to the page that does explain it.

<Steps>
<Step>
### Create an app

<InstallTabs commands={[{ verb: "create", packages: ["expo-app my-app --template blank-typescript"] }]} />

```bash
cd my-app
```

Already have an Expo app? Skip to the next step and run it from your app's root.
</Step>

<Step>
### Set up the project

<InstallTabs commands={[{ verb: "dlx", packages: ["delacour@alpha init --src . --install"] }]} />

One command writes `native-components.json`, wraps `metro.config.js` with Uniwind's transform,
creates `styles/global.css` with the theme, copies the root `provider` into `components/ui/`, and
installs what it needs with `expo install`. `--src .` puts everything at the project root, where
this template keeps its files — drop it in an app that has a `src/`.
</Step>

<Step>
### Add a Button

<InstallTabs commands={[{ verb: "dlx", packages: ["delacour@alpha add button --install"] }]} />

Copies `button` and the parts it renders into `components/ui/`, with imports rewritten for this
project. Every component page carries this command for its own component.
</Step>

<Step>
### Replace `App.tsx`

```tsx title="App.tsx"
import "./styles/global.css";
import { Button } from "./components/ui/button";
import { DelacourProvider } from "./components/ui/provider";
import { useState } from "react";
import { View } from "react-native";

export default function App() {
  const [count, setCount] = useState(0);

  return (
    <DelacourProvider>
      <View className="flex-1 items-center justify-center gap-4 bg-background">
        <Button onPress={() => setCount(count + 1)}>Pressed {count} times</Button>
        <Button variant="outline" onPress={() => setCount(0)}>
          Reset
        </Button>
      </View>
    </DelacourProvider>
  );
}
```

<Callout type="warn" title="The CSS import stays first">
Without it every component renders unstyled, and nothing logs an error. `DelacourProvider` is the
gesture root every press needs above it — leave it out and presses stop landing, just as silently.
</Callout>
</Step>

<Step>
### Run it

<InstallTabs commands={[{ verb: "dlx", packages: ["expo run:ios"] }]} />

The components use native modules — Reanimated, Gesture Handler — so this is a native build, not
Expo Go. The first one takes a few minutes; `expo run:android` is the same command for Android.
</Step>

<Step>
### Check the wiring

<InstallTabs commands={[{ verb: "dlx", packages: ["delacour@alpha doctor"] }]} />

Every check is a failure that produces no error on its own. If the button rendered and counts,
it passes; if something is off, `doctor` names the file and the fix.
</Step>
</Steps>
