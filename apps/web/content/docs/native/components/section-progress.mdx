## Usage

```tsx title="app/policy.tsx"
import { useScrollSections } from "@/hooks/use-scroll-sections";
import { SectionProgress } from "@/components/ui/section-progress";
import { Text } from "@/components/ui/text";
import { View } from "react-native";
import Animated from "react-native-reanimated";

const SECTIONS = [
  { id: "intro", title: "Introduction", body: "What this policy covers, and who it applies to." },
  { id: "pricing", title: "Pricing", body: "What each plan costs, and when you are billed." },
  { id: "faq", title: "Questions", body: "The answers people ask for most often." },
];

export default function Policy() {
  const sections = useScrollSections({ readingLine: 96 });

  return (
    <View className="flex-1">
      <Animated.ScrollView
        ref={sections.scrollRef}
        onScroll={sections.scrollHandler}
        scrollEventThrottle={16}
        contentContainerClassName="pb-32"
      >
        {SECTIONS.map((section) => (
          <View key={section.id} onLayout={sections.register(section.id)}>
            <Text.Header>{section.title}</Text.Header>
            <Text.Paragraph>{section.body}</Text.Paragraph>
          </View>
        ))}
      </Animated.ScrollView>

      <SectionProgress scroll={sections} value={sections.activeId} onValueChange={sections.scrollTo}>
        {SECTIONS.map((section) => (
          <SectionProgress.Item key={section.id} value={section.id}>
            {section.title}
          </SectionProgress.Item>
        ))}
      </SectionProgress>
    </View>
  );
}
```

`useScrollSections` tracks the scroll view; the pill reads its `progress` and `scrollY` through
`scroll`, its `activeId` as `value` and its `scrollTo` as `onValueChange`. The ring is drawn with Skia
and fills on the UI thread, so scrolling renders nothing — the label changes only when the section does.

<Callout type="warn">
Mount the pill as the **last child of the screen's container**, a sibling of the scroll view. It
positions itself absolutely inside that container and is not portalled. Leave bottom padding at the
end of the scroll content so the pill never covers the last line.
</Callout>

Each registered section must be a direct child of the scroll content: `onLayout` reports `y`
relative to its parent.

## Placements

Six placements, `offset` points in from the safe area. A `top-*` pill opens its panel downward and a
`bottom-*` one upward; `start` and `end` mirror under right-to-left.

<Preview id="section-progress/placements" />

```tsx
<SectionProgress placement="top-end" offset={12} …>…</SectionProgress>
```

## Reveal

The pill appears once the reader scrolls past `revealAt` (64 points by default) and stays from then
on, so it never blinks near the top. `revealAt={0}` shows it at once.

## Coloured sections

An item's `color` paints its marker in the panel, and the ring while that section is being read.

<Preview id="section-progress/colored-sections" />

```tsx
<SectionProgress.Item value="known-issues" color="warning">Known issues</SectionProgress.Item>
```

## Manual progress

`progress` overrides the scroll — a number or a shared value from 0 to 1. Small steps track
directly; a jump of more than a tenth eases over 180ms.

<Preview id="section-progress/manual-progress" />

```tsx
<SectionProgress progress={step / steps.length} revealAt={0} value={current}>…</SectionProgress>
```

## Controlled open

`isOpen` and `onOpenChange` hand the panel to you. The pill, an outside tap, the escape gesture and
Android back all close it through the same callback.

<Preview id="section-progress/controlled-open" />

```tsx
const [isOpen, setOpen] = useState(false);

<SectionProgress isOpen={isOpen} onOpenChange={setOpen} …>…</SectionProgress>
```

## Accessibility

- The pill is one button, read as "Sections, Pricing, 42 percent", with an expanded state.
- The percent only reaches React while a screen reader is running; with none, scrolling renders nothing.
- Opening moves focus to the active section. The panel is modal to VoiceOver, and the escape
  gesture closes it.
- Sections are buttons; the active one is announced selected. The ring and the markers are hidden.
- Android back closes the open panel.
- Reduce motion turns the panel's scale into a fade. The ring keeps tracking — it is information,
  not decoration.
