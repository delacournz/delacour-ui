The summary and API surface below are current. Worked examples and full prop tables are still

</Callout>

```tsx
import { Icon } from "@delacour/native-ui/icon";
import { IconHeart } from "@delacour/native-ui/icons/central";

<Icon icon={IconHeart} />;
```

**Sizes:** `xs` 14, `sm` 16, `md` 18, `lg` 20, `xl` 24, `2xl` 32 — the shared icon scale, which
`Spinner` reads too.

The full guide is [Icons](/docs/native/getting-started/icons); the precedence ladder is in
[Sizing](/docs/native/getting-started/sizing#precedence-weakest-first).

## Publishing defaults

```tsx
import { IconDefaultsProvider } from "@delacour/native-ui/icon";

<IconDefaultsProvider className="size-icon-lg" color="muted-foreground">
  {children}
</IconDefaultsProvider>;
```

`Button`, `Badge` and `ListGroup.ItemPrefix` all publish into this, so a bare `<Icon>` inside one
needs nothing at the call site.
