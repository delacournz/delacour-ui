Install Delacour packages from the CLI's own release line. An alpha CLI (`delacour@alpha`) adds `@delacour/react-native-ui@alpha` and `@delacour/react-native-charts@alpha`, and a stable CLI adds them untagged from `latest`. A peer on a Delacour package is still written as `>=0.0.0-0`, so either line satisfies it.
