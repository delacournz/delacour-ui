## Requirements

- **React Native 0.88+** on the **New Architecture** — Expo SDK 58+ qualifies. Built and tested on
  SDK 58 with React Native 0.88.
- **Node 20.19+**.
- **Uniwind 1.11+ with Tailwind CSS v4**, wired into Metro. Every `className` in the library is
  compiled by Uniwind in your app's Metro pipeline — without it nothing is styled. NativeWind cannot
  share the app; [migrate first](https://docs.uniwind.dev/migration-from-nativewind).
- **A development build**, not Expo Go. Reanimated, Gesture Handler and the keyboard controller are
  native modules.
- **Expo modules.** An Expo app has them; a plain React Native app adds them with one command.
- Let `expo install` pick native module versions. `npm install react-native-reanimated` (or any package manager's add) fetches the
  newest release, which fails at the linker on an older SDK rather than at install time.

## Optional peers

Resolved only if you import the subpath that needs them:

| Package | Needed by |
| --- | --- |
| `@delacour/react-native-bottom-sheet` | `BottomSheet` — the engine it skins |
| `@maplibre/maplibre-react-native` | `Map`. A native module with a config plugin: `expo install` it, add the plugin and rebuild the dev client |
| `@legendapp/list` | `Screen.LegendList`, `Screen.ChatList`, `BottomSheet.LegendList` |
| `expo-blur` | `@delacour/react-native-ui/expo/blur-layer` — `ScrollBlur`'s engine. A native module: `expo install` it and rebuild the dev client |
| `react-native-skia` | `Flow`, `Chart` and `Sketch` — the renderer, and `Sketch`'s PNG export — and `SectionProgress`'s ring. Version 3 or later, the package `@shopify/react-native-skia` was renamed to. A native module: `expo install` it, set Android `minSdkVersion` to 26 (`expo-build-properties`) and rebuild the dev client |
| `expo-router` | `@delacour/react-native-ui/expo/navigation-theme` |
| `react-native-screens` | native stack navigation |
| `react-native-teleport` | `BottomSheet` — the engine's portal. A native module: `expo install` it and rebuild the dev client |

## Or let the CLI do it

One command in an Expo app wires Uniwind, the theme and the provider, and copies the component
source into your project so you own it. See the [Quick start](/docs/native/getting-started).
