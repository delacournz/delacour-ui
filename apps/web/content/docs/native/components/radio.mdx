## Usage

```tsx
import { Radio } from "@delacour/native-ui/radio";
```

```tsx
<Radio.Group accessibilityLabel="Plan" selected={plan} onSelected={setPlan}>
  <Radio value="monthly"><Radio.Label>Monthly</Radio.Label></Radio>
  <Radio value="annual"><Radio.Label>Annual</Radio.Label></Radio>
</Radio.Group>
```

## Variants

`secondary` fills the ring; `primary` leaves it hollow.

<Preview id="radio/variants-and-states" />

```tsx
<Radio variant="primary" value="monthly">Monthly</Radio>
<Radio variant="secondary" value="annual">Annual</Radio>
```

## Descriptions

There is no `Radio.Description` — compose a `Text.Caption` inside the row and it stays within the
one tap target and inside the accessible name.

<Preview id="radio/per-option-description" />

```tsx
<Radio value="standard">
  <View className="min-w-0 shrink gap-0.5">
    <Radio.Label>Standard</Radio.Label>
    <Text.Caption>Arrives in three to five days.</Text.Caption>
  </View>
</Radio>
```

## Trailing indicator

Write a `Radio.Indicator` last and the row spreads to push the ring to the far edge.

<Preview id="radio/custom-indicator" />

```tsx
<Radio value="standard">
  <View className="min-w-0 shrink gap-0.5">
    <Radio.Label>Standard delivery</Radio.Label>
    <Text.Caption>Arrives in three to five days.</Text.Caption>
  </View>
  <Radio.Indicator />
</Radio>
```

## Inside a field

The group names no state of its own — `isInvalid` and `isDisabled` reach every ring from the
enclosing `Field`.

```tsx
<Field isInvalid={plan === undefined}>
  <Field.Label>Plan</Field.Label>
  <Radio.Group accessibilityLabel="Plan" onSelected={setPlan} selected={plan ?? null}>
    <Radio value="free">Free</Radio>
    <Radio value="pro">Pro</Radio>
  </Radio.Group>
  <Field.Error>Pick a plan to continue.</Field.Error>
</Field>
```

## Reading the radio's state

Use `useRadio()` to read the settled state from a custom child, and `useRadioGroup()` for the
group's own.

```tsx
import { useRadio, useRadioGroup } from "@delacour/native-ui/radio";
```

## API Reference

### Anatomy

| Part | What it is |
| --- | --- |
| `Radio` | One option. A `Pressable` that selects its `value` in the enclosing group |
| `Radio.Label` | The option's text, inside the tap target |
| `Radio.Indicator` | The dot. Accepts custom children to replace the default glyph |
| `Radio.Group` | Owns the selected value and the shared axes |

### Radio

A radio is a `Pressable`, so `feedback`, `haptic` and the rest are inherited — see
[Pressable](/docs/native/components/pressable). The shared axes resolve
`group ?? own ?? field ?? default`.

### Radio.Group

Owns which radio is selected. Extends `ViewProps`.

<TypeTable
  type={{

    defaultSelected: { type: "string | null" },

    variant: { type: '"primary" | "secondary"' },
    size: { type: '"sm" | "md" | "lg"' },
    orientation: { type: '"vertical" | "horizontal"', default: '"vertical"' },
    isInvalid: { type: "boolean" },

    className: { type: "string" },
  }}
/>

<Callout type="warn">
A group renders no legend, and React Native has no `aria-labelledby` to tie it to a `Field.Label`
above it — so pass `accessibilityLabel` or the group is announced without a name.
</Callout>
