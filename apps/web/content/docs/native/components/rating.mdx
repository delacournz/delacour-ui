## Usage

```tsx title="app/index.tsx"
import { Rating } from "@/components/ui/rating";
import { useState } from "react";
import { View } from "react-native";

export default function Example() {
  const [score, setScore] = useState(3);

  return (
    <View className="flex-1 items-center justify-center p-4">
      <Rating value={score} onChange={setScore}>
        <Rating.Stars accessibilityLabel="Your rating" />
        <Rating.Output />
      </Rating>
    </View>
  );
}
```

## Half stars

`step={0.5}` splits every star at its centre.

<Preview id="rating/half-stars" />

```tsx
<Rating step={0.5} value={score} onChange={setScore}>
  <Rating.Stars accessibilityLabel="Your rating" />
</Rating>
```

## Colours

`color` paints the filled stars; an empty star looks the same at every colour.

<Preview id="rating/colours" />

## Read-only

`isReadOnly` shows any value — an average of 4.3 fills part of the fifth star — without taking a touch.

<Preview id="rating/read-only" />

```tsx
<Rating className="flex-row items-center gap-2" isReadOnly size="sm" value={4.3}>
  <Rating.Stars accessibilityLabel="Average rating" />
  <Rating.Output>{({ value }) => `${value.toFixed(1)} · 128 reviews`}</Rating.Output>
</Rating>
```

## Clearing

`allowClear` lets a tap on the star already held withdraw the rating.

```tsx
<Rating allowClear defaultValue={4}>
  <Rating.Stars accessibilityLabel="Your rating" />
</Rating>
```

## Star count

`maxValue` is how many stars the row draws.

```tsx
<Rating defaultValue={7} maxValue={10} size="sm">
  <Rating.Stars accessibilityLabel="Score out of ten" />
  <Rating.Output>{({ value, count }) => `${value} / ${count}`}</Rating.Output>
</Rating>
```

## In a form

A `Field` cascades `isInvalid` and `isDisabled`, and the empty stars turn destructive too.

<Preview id="rating/a-review" />

```tsx
<Field isInvalid={score === 0}>
  <Field.Label>Required</Field.Label>
  <Rating value={score} onChange={setScore}>
    <Rating.Stars accessibilityLabel="Required rating" />
  </Rating>
  <Field.Error>{score === 0 ? "Choose at least one star." : undefined}</Field.Error>
</Field>
```

<Callout type="warn">
Label the row with `accessibilityLabel` on `Rating.Stars`, not on the root. The stars are the
control screen readers adjust; without a label they say only "Rating".
</Callout>

## API Reference

### Anatomy

| Part | What it is |
| --- | --- |
| `Rating` | Owns the value, the count, the step and the axes |
| `Rating.Stars` | The row of stars — the drag surface and the adjustable control |
| `Rating.Output` | The value, formatted. Give it a function to label it yourself |
