```ts
import { dynamicDetent, keyboardLift, positionFor, UNMEASURED } from "@delacour/react-native-bottom-sheet/core";
```

`@delacour/react-native-bottom-sheet/core` is every number the package computes and nothing that
renders. Nothing under it imports a runtime value from React, React Native, Reanimated, Gesture
Handler, keyboard-controller, safe-area-context or teleport, which is what lets a skin re-export the
footer's inset rules without mounting a sheet — and what lets the whole of it, the footer-on-keyboard
proof included, run under `bun test` with no simulator.

```ts
import { footerTop, keyboardLift } from "@delacour/react-native-bottom-sheet/core";

const lift = keyboardLift({ keyboardHeight: 336, progress: 1, band: 34, behavior: "interactive", gapBelow: 0 });
const top = footerTop({ sheetHeight: 420 + lift, keyboardHeight: 336, footerContentHeight: 72, band: 0 });
```

## Height space

Every value is a **height**: pixels of sheet visible above its resting bottom line. `0` is closed,
detents ascend, and `UNMEASURED` (`-1`) is a measurement that has not happened. `translateY` is
derived from a height only at the moment a view needs it, by `positionFor`, and nowhere else.

## The formulas

With `C` the container height, `inset` the safe-area bottom, `kb` the owned keyboard within the
container and `p` keyboard-controller's `progress`:

```txt
restingBottom = detached ? bottomOffset + inset : 0          closedHeight = −restingBottom
available     = C − restingBottom                            maxHeight = available
band          = detached ? 0 : inset                         bandNow = band · (1 − p)
footerHeight  = hasFooter ? footerContent + bandNow : 0
dynamicDetent = min(handle + content + (hasFooter ? footerContent : 0) + band, maxDynamicContentSize, available)
detents       = sortAsc(unique(normalize(spec, available) ∪ {dynamicDetent if dynamicSizing}))
keyboardLift  = behavior ∈ {interactive, extend} ? max(0, kb − band · p − (detached ? restingBottom : 0)) : 0
height        = clamp(base + keyboardLift, closedHeight, maxHeight)
translateY    = C − restingBottom − height
index         = piecewise(base, [closedHeight, …detents] → [−1, 0, 1, …])      base, never height
contentArea   = max(0, min(maxHeight, highest + keyboardLift) − handle − footerHeight − kb − (hasFooter ? 0 : bandNow))
footerTop     = max(0, height − kb − footerContent − bandNow)
backdrop      = index ≥ appearsOn ? opacity : index ≤ disappearsOn ? 0 : linear
```

`base` is the one value a gesture or an animation writes — the keyboard-free height. Everything
else is derived from it on the UI thread, one `useDerivedValue` per line above.

## The flat worklets

Most functions here carry a `"worklet"` directive and run on the UI thread every frame of a drag.
Each calls nothing and closes over nothing but module-scope constants — a module-scope worklet that
called another would bind at import time and hand the UI thread `undefined is not a function` the
moment a finger landed. A worklet you build **inside a hook** is captured by ordinary closure and
may call any of them, which is how the pan composes `resistOverDrag` and `selectSnapHeight` without
duplicating either.

A degenerate input returns a finite number, never `NaN`: one `NaN` written into `base` freezes a
sheet permanently with nothing on screen to say why.

## Detents

| Export | What it does |
| --- | --- |
| `parseDetent(spec)` | One `DetentSpec` to `{ kind: "px" \| "percent", value }`, as a `Result` |
| `normalizeDetents(spec, available)` | Ascending, unique, clamped; invalid entries skipped. Worklet |
| `dynamicDetent({ handleHeight, contentHeight, footerContentHeight, hasFooter, band, available, maxDynamicContentSize? })` | The content's own detent. Worklet |
| `indexForHeight(height, detents, closedHeight)`, `heightForIndex(index, detents, closedHeight)` | Piecewise-linear over `[closed, …detents]`, clamped. Worklets |
| `selectSnapHeight({ height, velocity, detents, closedHeight, projection })` | The candidate nearest `height + projection · velocity`. Worklet |
| `resistOverDrag(height, min, max, factor)` | Slope one at the edge, square root beyond; factor `0` clamps. Worklet |
| `sheetState(base, height, detents, closedHeight, maxHeight)` | `SHEET_STATE.CLOSED \| OPENED \| EXTENDED \| OVER_EXTENDED \| FILL`. Worklet |

## Keyboard

| `keyboardInContainer(rawKeyboardHeight, containerBottomOffset)` | keyboard-controller's negative height to the positive overlap with the frame. Worklet |
| `keyboardLift({ keyboardHeight, progress, band, behavior, gapBelow })` | The lift: keyboard less the band in step with progress, less a detached gap. Worklet |
| `resolveKeyboardOwner(input)` | Whose keyboard it is, under `keyboardScope`, sticky through a transition |
| `isInputInsideSheet(input)` | The `inside` scope's geometry test, in window space. Worklet |
| `keyboardStep(input)` | What a behaviour does this frame: `apply`, `restore`, `release` or nothing |
| `contentArea({ sheetHeight, handleHeight, footerHeight, keyboardHeight, trailingBand })` | What the body may fill, never negative. Worklet |
| `acceptContainerLayout(input)` | Refuses Android's `adjustResize` double-count while a keyboard is up |
| `shouldResetKeyboardAnimation(state)` | The stale keyboard-controller guard. Worklet |
