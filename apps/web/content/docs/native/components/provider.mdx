## Usage

```tsx
import { DelacourProvider } from "@delacour/native-ui/provider";
```

```tsx
<DelacourProvider>{children}</DelacourProvider>
```

Mount it once, around everything — a root layout, an `App.tsx`.

## Layers

Five, outermost first: `GestureHandlerRootView` → `SafeAreaProvider` →
`KeyboardProvider` → `<KeyboardStateSync />` beside the children →
`BottomSheetModalProvider` around them.

<Callout type="warn">
The order is load-bearing, and one failure is silent: without the gesture root every `Pressable`
stops responding — no error, no warning, presses simply stop landing. Nesting a second copy of the
provider breaks the keyboard values the same quiet way, so mount exactly one. The full reasoning is
in [Provider](/docs/native/getting-started/provider).
</Callout>
